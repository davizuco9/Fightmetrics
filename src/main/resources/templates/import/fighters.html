Importar luchadores desde CSV

Esta herramienta permite cargar varios luchadores desde un único archivo CSV.

Formato esperado

El archivo debe usar punto y coma como separador. 

firstName;lastName;nickname;nationality;weightClass;heightCm;reachCm;wins;losses;draws;active
Ilia;Topuria;El Matador;España;FEATHERWEIGHT;170;175;17;0;0;true
Islam;Makhachev;;Rusia;LIGHTWEIGHT;178;179;27;1;0;true

Categorías admitidas:

  • FLYWEIGHT
  • BANTAMWEIGHT
  • FEATHERWEIGHT
  • LIGHTWEIGHT
  • WELTERWEIGHT
  • MIDDLEWEIGHT
  • LIGHT_HEAVYWEIGHT
  • HEAVYWEIGHT
